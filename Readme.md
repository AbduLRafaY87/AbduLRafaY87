## 🧑‍💻 A little about me

I'm **Abdul Rafay**, a developer and builder from **Karachi, Pakistan**.

I started coding because I wanted to understand how things work on the internet. Somewhere along the way, coding turned into something bigger — building products, working with real organizations, teaching others, experimenting with ideas, and eventually starting my own studio.

Today, I work across **development, product design, UI/UX, and digital experiences**.

I'm particularly interested in the space where:

```text
        DESIGN
           ↓
     USER EXPERIENCE
           ↓
        SOFTWARE
           ↓
       REAL IMPACT
```

I don't just want to write code that works.

**I want to build things people actually enjoy using.**

# 🧠 How I Think About Building

I like keeping my development process simple:

```text
   ┌─────────────┐
   │   DISCOVER   │
   └──────┬──────┘
          ↓
   ┌─────────────┐
   │    DESIGN    │
   └──────┬──────┘
          ↓
   ┌─────────────┐
   │    BUILD     │
   └──────┬──────┘
          ↓
   ┌─────────────┐
   │    TEST      │
   └──────┬──────┘
          ↓
   ┌─────────────┐
   │    SHIP      │
   └──────┬──────┘
          ↓
   ┌─────────────┐
   │   IMPROVE    │
   └─────────────┘
```

**Good software isn't just functional.**

It should be understandable, maintainable, accessible, and pleasant to use.
